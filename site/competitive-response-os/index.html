      AI proposes. People decide.

      Six rules are built in. Nobody can skip them, and neither can the AI.

      • Humans decideAI drafts. Only an authorized person approves.
      • One approval, one versionA change makes a new version and pauses unsent work.
      • Confirmed means confirmed"Confirmed" shows only after Jira returns a key.
      • No duplicate tasksA retry resends only the failed task, with the same key.
      • Missing is never zeroNo data shows "Unavailable", never €0.
      • Restricted stays restrictedHidden values never leak into totals or exports.
