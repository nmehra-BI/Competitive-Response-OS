Five status grammars

Each dimension has its own icon family, shape, vocabulary and fixed position. Labels always render; colour is never the only cue.

Priority
How much attention should this get? Monochrome bars, never hue.
HighMediumLowOverridden

How sure are we that it happened? Shield family + semantic hue.
